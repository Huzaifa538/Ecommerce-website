# Shopixo — Ecommerce Website
A fully responsive multi-page ecommerce website built with HTML, CSS, and JavaScript.
**Live Demo:** https://huzaifa-ecommerce.vercel.app
## Pages
- Home, Products listing, Product detail, Cart, Checkout, Login / Signup
## Features
- Product catalog with cart and checkout flow
- Login and signup pages
- Fully responsive design
## Tech Stack
- HTML5
- CSS3
- JavaScript
## Run Locally
Just open `index.html` in your browser — no build step needed.
